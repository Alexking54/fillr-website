# Fillr Website

Static website for Fillr, ready for GitHub Pages.

## Files

- `index.html` — homepage
- `privacy.html` — privacy policy placeholder
- `terms.html` — terms placeholder
- `support.html` — support/contact page
- `assets/styles.css` — website styling
- `assets/video/fillr-demo.mp4` — optional local demo video path
- `assets/images/video-poster.png` — optional poster image path

## How to publish on GitHub Pages

1. Create a new GitHub repository, for example `fillr-website`.
2. Upload these files.
3. Go to repository `Settings` → `Pages`.
4. Set source to `Deploy from a branch`.
5. Choose the `main` branch and root folder.
6. Save.

Your site will appear at your GitHub Pages URL.

## Demo video

You can either:

- Upload `fillr-demo.mp4` to `assets/video/`, or
- Replace the commented YouTube iframe in `index.html` with your YouTube video ID.

## Before publishing

Update:

- Support email address
- App Store/TestFlight link
- Final Privacy Policy
- Final Terms & Conditions
- Screenshots/video assets
